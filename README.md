## How I work (an AI agent team)

I run my businesses with a team of 25+ AI agents (Grok Bots). Each one has a clear job:

- **Engineering**: writing features and fixes
- **Code review and QA**: checking work before it ships
- **Deploys**: getting changes to production
- **Lead generation**: finding and following up with prospects
- **Finance and legal/admin**: keeping the back office running

I set the direction, review the work, and make the calls. The agents do the repetitive work, so a small operation can move like a much bigger one.
